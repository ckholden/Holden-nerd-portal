Privacy Policy: Claude Gmail personal

Last Updated: October 22, 2026

1. Who this covers

Claude Gmail personal is a private tool with a single user, Christian Holden. It works only with his own Gmail account. It is not offered to anyone else.

2. Google data it accesses

With Christian's permission through Google sign-in, the tool can:

  • Read and search his email messages, threads, labels and attachments (Gmail read-only access).
  • Create drafts in his mailbox (Gmail compose access).
  • See his name and email address, to confirm which account is signed in.

The tool does not send, delete, archive or relabel email.

3. How the data is used

Email is read only when Christian asks his AI assistant to do something with it, such as find a message, summarize his inbox or draft a reply. The relevant email content is passed to Claude, the AI model made by Anthropic, to answer that request inside Christian's own assistant session. Anthropic's handling of that conversation is covered by the Anthropic Privacy Policy and Christian's account settings.

Gmail data is not sold, not used for advertising, not shared with anyone else, and not used by this tool to train AI models.

4. Storage

The Google sign-in token is stored only on Christian's personal computer. Attachments are saved there only when he asks for them. There is no server or database that holds Gmail data.

5. Google API Services User Data Policy

Claude Gmail personal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Removing access

Access can be removed at any time from Google Account permissions. Removing it, or deleting the token from the computer, stops all access right away.

Questions about this policy: contact@holdenportal.com
