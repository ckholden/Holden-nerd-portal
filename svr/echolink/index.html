HOLDEN1 Bridge

This toggles the audio bridge only — the same thing el on / el off does in the Holden DMR chat box, writing the identical Firebase command. It does not stop the node: with the link off, KJ7DTS-L stays online and connectable, callers just reach a node that isn’t bridged to anything. The link is also OFF after every reboot by construction.

Directory Identity — what the EchoLink directory and callers see

⚠ Saving restarts svxlink, which disconnects anyone currently on the node. Nothing is sent unless a value actually changed, and the agent waits at least 90 s between restarts.

Location is the free-text field most sysops use as a note — it is what shows beside your callsign in the EchoLink directory. It is clamped to 27 characters because the directory truncates long values.

The node applies this by polling aprs/control/echolink_cfg, which is write-gated to you by Firebase rules. It is deliberately not read from aprs/svr — that area accepts writes from anyone, so a stranger could otherwise rewrite your callsign’s public listing and the greeting read to every caller.

If a saved value makes svxlink fail to start, the node restores the previous config automatically and reports it below — a bad edit cannot leave the node dead. (A stray newline in Description did exactly that on 2026-08-17 and took 5 failed restarts to notice.)
