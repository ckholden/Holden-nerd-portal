This toggles the audio bridge only — the same thing el on / el off does in the Holden DMR chat box, writing the identical Firebase command. It does not stop the node: with the link off, KJ7DTS-L stays online and connectable, callers just reach a node that isn’t bridged to anything. The link is also OFF after every reboot by construction.
