Installing

  1. Run the installer you just downloaded.
  2. Windows will say “Windows protected your PC.” That is SmartScreen noticing the installer isn't code‑signed, not a virus warning. Click More info, then Run anyway.
  3. Launch Holden On Line from the Start menu.
  4. Sign on with the screen name you were given.

Getting a screen name

Accounts are invite‑only — there is no sign‑up form, and there never will be. Ask Christian for a screen name and the connection settings.
